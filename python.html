Learn Python from zero: a free beginner path

Go from your first lines of code to a small project you can explain. Use one main course, practice as you go, and keep a finished project as proof of what you learned.

Free resourcesNo experience required5 milestones

Who this path is for

People new to Python who can spend a few hours each week practicing. The course pages and platforms may change; check their current access and requirements before starting.

What you’ll finish with: a small command-line program, such as a quiz, expense tracker, or number guessing game, plus a record of the concepts you used.

1

Set up and write your first program

Start with freeCodeCamp’s current Python course. Learn how to run code, use print statements, and work with values. Don’t rush ahead until you can change a short example and predict its output.

Start freeCodeCamp Python course ↗
Milestone: write a program that greets someone by name.
2

Learn the core building blocks

Work through variables, strings, numbers, conditions, loops, lists, and dictionaries. After each topic, make a tiny variation from memory before checking the lesson again.

Continue the guided lessons ↗
Milestone: build a number guessing game with a loop and hints.
3

Practice functions and debugging

Break repeated steps into functions. Learn to read error messages and test one small change at a time. Use the official Python tutorial as a reference when you want a second explanation; it assumes some basic programming knowledge.

Use the official Python tutorial as a reference ↗
Milestone: write three small functions and test different inputs.
4

Build one complete beginner project

Choose a project that matters to you: a simple quiz, personal expense tracker, or study timer. Plan the inputs and outputs first; build one feature at a time. Add input checks so it behaves sensibly when someone types something unexpected.

Explore Python fundamentals and projects ↗
Milestone: finish a working version and explain how its main parts fit together.
5

Review, improve, and choose what’s next

Write down what your project does, what you learned, and one improvement you would make. Then choose a direction: automate a task, analyze data, build a website, or continue with computer science fundamentals.

Browse freeCodeCamp’s current learning catalog ↗
Milestone: save a finished project and a short reflection on your learning.

How to make the path work

Spend more time writing and changing code than watching lessons. Keep a small “things I can now do” note. If stuck, reduce the problem until you can test one piece at a time.

Suggested pace: 3–5 focused sessions a week. Treat this as a flexible guide, not a promise of job readiness or a fixed completion time.
